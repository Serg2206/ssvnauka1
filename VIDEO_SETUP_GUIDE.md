# Настройка видео для платформы SSVНаука

## 📹 Важно: Добавление видеоконтента

Платформа поддерживает встраивание видео из YouTube и Vimeo. Для полноценной работы видеотеки необходимо добавить ссылки на реальные видеозаписи хирургических операций.

### Поддерживаемые форматы URL:

#### YouTube:
```
https://www.youtube.com/embed/VIDEO_ID
```

#### Vimeo:
```
https://player.vimeo.com/video/VIDEO_ID
```

### Как добавить видео:

1. **Через админ-панель базы данных:**
   ```sql
   UPDATE "Video" SET "videoUrl" = 'https://www.youtube.com/embed/YOUR_VIDEO_ID' WHERE id = 'video_id';
   ```

2. **Через seed скрипт** (`scripts/seed.ts`):
   - Найдите массив `videos`
   - Обновите поле `videoUrl` для каждого видео:
   ```typescript
   {
     title: 'Название операции',
     description: 'Описание',
     videoUrl: 'https://www.youtube.com/embed/YOUR_VIDEO_ID',
     // ... остальные поля
   }
   ```

3. **Заполнить базу заново:**
   ```bash
   cd nextjs_space
   yarn prisma db push --force-reset
   yarn prisma db seed
   ```

### Требования к видео:

✅ Видео должно разрешать встраивание (embed enabled)  
✅ Для YouTube: настройки приватности должны быть "Публичное" или "Доступно по ссылке"  
✅ Для Vimeo: в настройках видео включить "Allow embedding"

### Текущее состояние:

Сейчас в базе данных используются демонстрационные URL, которые могут быть недоступны. После замены на реальные URL хирургических операций, видеоплеер будет полностью функциональным.

### Проверка работоспособности:

После добавления своих видео URL:
1. Откройте страницу `/videos`
2. Выберите любое видео из списка
3. Видео должно загрузиться и воспроизводиться на странице
